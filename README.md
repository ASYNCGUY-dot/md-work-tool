# MD 워크툴

온라인 MD(머천다이저)의 매출·목표·광고·프로모션·소싱 업무를 한 화면에서 관리하는 브라우저 앱입니다. 빌드 없이 `index.html` 하나로 동작하며, 업무 자료는 사용하는 브라우저 안(IndexedDB)에만 저장되고 외부로 전송되지 않습니다.

## 주요 기능

- **매출 대시보드·채널·상품 분석**: 기간 비교(직전 기간·전월 동기간·전년 동기), 채널·상품별 실적과 이익률
- **목표·KPI**: 월 목표와 계획 대비 달성률, ROAS·전환율 목표, 자료 마감 확인일 기준 판정
- **광고 성과**: 플랫폼 광고 리포트 기준 ROAS, CTR·CPC·CPA·캠페인별 분석
- **매출 변동 분석·개선 제안**: 방문×전환율×객단가 분해, 내부·외부 요인 기록
- **프로모션·경쟁 상품 비교·원가/판매가 계산·소싱·정산 대사·발주**
- **가져오기 전 확인**: 플랫폼 내려받기 파일의 열 이름 행·열 매핑 자동 인식과 직접 지정, 반영 전 미리보기
- **보고서 자동 작성**: 인쇄·PDF·메신저 텍스트·엑셀, 확정본 보관과 계산 기준 표시
- **저장 신뢰성**: IndexedDB 원자적 저장, 여러 탭 덮어쓰기 방지, 백업·복원(형식 검사 후 복원)

## 실행

정적 파일이라 아무 웹 서버로 열면 됩니다.

```bash
python -m http.server 8765
```

브라우저에서 `http://localhost:8765`를 엽니다. 처음에는 예시 데이터가 보이며, [데이터 관리]에서 양식을 받아 내 자료를 올리면 예시 데이터는 비워집니다.

## 테스트

```bash
node --test "tests/*.test.cjs"
```

`test-data/`의 파일은 화면 점검용 더미 자료(가상 회사·가상 브랜드)이며 `make_dummy.py`로 다시 만들 수 있습니다.

## 기술

순수 JavaScript(빌드 없음), Chart.js 4.4.1, SheetJS 0.18.5(cdnjs).
